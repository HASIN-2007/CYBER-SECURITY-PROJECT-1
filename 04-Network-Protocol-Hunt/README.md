# 🔎 Network Protocol Hunt — Cybersecurity Investigation Lab

## 📌 Project Overview

This project simulates a basic network security investigation in which network traffic is analyzed to identify communication protocols, associated ports, and potentially risky network services.

The application processes simulated network traffic, identifies protocols, classifies their security risk, detects high-risk communication, and generates an automated investigation report.

This is a controlled local cybersecurity simulation designed for educational purposes.

---

## 🎯 Objectives

The main objectives of this project are:

1. Understand common network protocols.
2. Identify protocols from network traffic.
3. Associate protocols with their standard ports.
4. Analyze the security characteristics of network protocols.
5. Identify potentially insecure communication.
6. Detect high-risk protocols such as FTP and TELNET.
7. Classify security findings by severity.
8. Generate a network investigation report.
