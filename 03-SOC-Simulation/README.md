# 🛡️ SOC Simulation — Security Operations Center Lab

## 📌 Project Overview

This project simulates a basic Security Operations Center (SOC) workflow for detecting and analyzing suspicious security events from log data.

The application reads security logs, analyzes authentication and access events, identifies suspicious activity, assigns alert severity, and automatically generates an incident report.

This is a controlled local cybersecurity simulation designed for educational purposes.

---

## 🎯 Objectives

The main objectives of this project are:

1. Understand the basic workflow of a Security Operations Center.
2. Analyze security log entries.
3. Detect repeated failed login attempts.
4. Identify possible brute-force attacks.
5. Detect unauthorized access attempts.
6. Identify successful authentication after repeated failures.
7. Classify security alerts by severity.
8. Generate an automated incident report.
